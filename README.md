# Snow Plugins

Past plugins and new ports for **Snow**, a third-party mobile Discord client. Maintained by **Mime | N0_.q3** with credit to every original author.

## Snow repository

Plugins built with the Snow plugin SDK are published as a Snow repository. In Snow, open Plugins, then the options menu, then Repositories, then Add repository, and enter:

```
https://xmimiez.github.io/Snow-Plugins/repository.json
```

Their sources are in `plugins/<id>/`. This table is generated by `bun run build:readme`.

## Snow install links

InstallLinks sends a `snow://` install-plugin URL, not a GitHub hyperlink:

```text
snow://snow?id=-1&command=install-plugin&params=https://raw.githubusercontent.com/xMimiez/Snow-Plugins/main/Decor/manifest.json
```

`/snowlink url:` posts that string. Taps on `snow://` open a sheet with the manifest URL, copy buttons, and Snow Settings → Plugins → Install from URL instructions. The documented compatibility API does not expose installation or enabling of other plugins.

## Development

Snow SDK plugins: edit `plugins/<id>/src/` (shared code is in `shared/`), then run `bun install --frozen-lockfile`, `bun run typecheck` and `bun run build`. The Publish workflow builds `main` and deploys the repository to GitHub Pages.

Bunny releases: edit `src/` then run `npm ci` and `npm run build:bunny`. The build emits Bunny spec-3 `manifest.json` + `index.js`.
